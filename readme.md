This repo is a playground or labs to experiment LIbs that abstract or enchance SQL with clojure and also other alternatives such as Duct, Component, Ring, Pedestal, etc.

here is the list of libs to experiment with:

- next.jdbc
- hugsql
- Clojure.JDBC - https://clojure.github.io/java.jdbc/
- Duct - https://github.com/duct-framework/duct
- Component - https://github.com/stuartsierra/component
